# 飞书生态开源项目雷达

这是一个追踪 **飞书 / Lark 开源生态项目** 的社区雷达。

我们会定期观察 GitHub 上和飞书生态相关的开源项目，包括 Bot、AI Agent、MCP、CLI、文档工具、IM Bridge、多 Agent 协作等方向，并整理成雷达报告。

## 看最新雷达

雷达报告会发布在本仓库的 **Issues** 里：

👉 [查看飞书生态雷达报告](https://github.com/lark-radar/lark-radar/issues)

## 提交你的项目

如果你有飞书 / Lark 相关的开源项目，欢迎通过 PR 加入追踪列表。

请修改 [`projects.md`](./projects.md)，按照表格格式新增一行：

```markdown
| [owner/repo](https://github.com/owner/repo) | 分类 | 简短说明 |
```

示例：

```markdown
| [example/lark-bot](https://github.com/example/lark-bot) | Bot | 飞书机器人框架 | 社区项目 |
```

合并后，该项目会进入后续雷达扫描范围。

## 收录范围

项目需要和飞书 / Lark 生态明确相关，例如：

- 飞书 Bot / IM Bridge
- 飞书 AI Agent / 多 Agent 协作
- 飞书 MCP / CLI / Skill 工具
- 飞书文档导出、备份、Markdown 转换
- 基于飞书开放平台的开发者工具
